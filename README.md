# 猫咪日常簿：微信小程序 Demo

这是一个原生微信小程序 Demo，先验证两个核心价值：

1. 快速记录真实照护信息：猫砂数量、湿粮反馈、护理完成情况；
2. 用“地点 → 互动方式 → 不同回应”实现一个可扩展的猫咪小剧场。

它不包含登录、云端同步、真实图片上传、系统推送或健康诊断；这些都应在确认自己会持续使用之后再做。

## 从这里开始

如果你的目标是把 Demo 变成真正属于你家猫的初版，请按这个顺序阅读：

1. [V0_BUILD_ORDER.md](./V0_BUILD_ORDER.md)：你和我各自要做什么、先做什么；
2. [MATERIAL_MANIFEST.md](./MATERIAL_MANIFEST.md)：首版 19 项物料的可勾选清单；
3. [ASSET_PROMPTS.md](./ASSET_PROMPTS.md)：参考图如何搭配、文件如何命名、可复制的 AI 提示词；
4. 素材准备好后，再把 approved 文件交给代码接入。

## 如何查看

1. 安装并打开微信开发者工具；
2. 选择“导入项目”；
3. 项目目录选择本文件夹；
4. AppID 可以先使用测试号或保留 Demo 配置；
5. 点击“编译”，并通过“预览”在手机微信中查看。

## Demo 可以做什么

- 在“记录”页按大/中/小分别录入尿团、屎团，选择湿粮和一句观察；
- 在“湿粮库”页录入品牌、口味、湿粮类型、常用分量与使用状态；
- 在“今天”页查看当天摘要，并记录护理事项完成；
- 在“管理提醒”页修改每项护理的提醒周期；
- 在“小剧场”页逐个地点寻找猫咪；找到后可互动、看到回应、等它躲起来再寻找，或看它过渡到新场景；
- 在“日记”页分别查看真实记录和虚拟小剧场回忆。

所有数据仅保存在当前设备的小程序本地存储中。清理微信缓存、卸载小程序或更换设备都可能导致数据无法恢复，因此这个版本只适合演示和学习。

## 后续最值得做的三件事

1. 阅读 [ASSET_PROMPTS.md](./ASSET_PROMPTS.md)，把 `utils/scenes.js` 里的地点、互动与回应替换成你家猫的真实习惯与素材；
2. 给记录页接入照片选择、压缩与稳定的文件保存方案；
3. 在连续使用 7 天后，再决定是否接入云端备份、订阅提醒、AI 周报和白名单访问；具体路线见 [ACCESS_AND_REMINDERS.md](./ACCESS_AND_REMINDERS.md) 与 [ROADMAP.md](./ROADMAP.md)。

## 项目结构

```text
pages/index      今天：今日照护摘要
pages/record     记录：猫砂与湿粮
pages/care       护理提醒设置
pages/play       猫咪小剧场
pages/timeline   真实日记与小剧场回忆
pages/food       湿粮库录入与下拉选择
utils/data.js    本地数据、日期和提醒逻辑
utils/scenes.js  小剧场回应与完整场景图片素材接口
```

护理提醒的周期只是用于演示“可配置提醒”的界面与逻辑，不代表适用于任何猫咪的护理或用药周期。请根据你的实际安排、产品说明或兽医建议设置。
